# Temperature initial and boundary conditions {#temperature}

DES3D solves the heat equation only when thermal diffusion is turned on
(see [Modeling thermal evolution](../theory/thermalevolution.md) for the
discretization):

```cfg
[control]
has_thermal_diffusion = yes   # default; set to no to skip the heat solve entirely
```

## Boundary conditions

Temperature boundary conditions are not configurable per-side the way
[velocity and stress boundary conditions](./run) are. Exactly one boundary
condition is enforced, every step:

```cfg
[bc]
surface_temperature = 273   # K, Dirichlet: held fixed at the top boundary (z1) every step
mantle_temperature = 1600   # K, used only to build the initial profile below
```

Every other boundary, meaning the bottom and all sides, is insulating (zero
heat flux) and cannot currently be changed to a prescribed temperature.

:::caution `mantle_temperature` is not a running boundary condition
`mantle_temperature` only shapes the **initial** temperature profile (see
below). It is not re-applied at the bottom boundary while the simulation
runs: once the run starts, the bottom and sides are free to warm or cool
by diffusion alone, bounded only by the no-flux condition. If you need the
base of the model held at a fixed temperature throughout the run, you must
do so indirectly, e.g. by keeping the model tall enough that the bottom
stays near `mantle_temperature` for the run's duration.
:::

## Initial temperature profile

`ic.temperature_option` selects how the initial temperature field is built:

| `temperature_option` | Profile |
|---|---|
| `0` (default) | Uniform half-space cooling |
| `1` | Continental thermal gradient |
| `2` | Equilibrium temperature for crustal radiogenic heating |
| `3` | Continental thermal gradient with adiabatic mantle |
| `90` | Read from an external grid (e.g., generated by COMSOL) |

### `temperature_option = 0`: uniform half-space cooling

The classic error-function cooling profile between `surface_temperature`
and `mantle_temperature`, using the thermal diffusivity of material `0`
(`therm_cond[0] / (rho0[0] * heat_capacity[0])`):

```cfg
[ic]
temperature_option = 0
oceanic_plate_age_in_yr = 60e6   # age of the plate, used in the half-space cooling profile
```

### `temperature_option = 1`: continental thermal gradient

A steady-state continental geotherm (crust over mantle) with an
exponentially decaying radiogenic heat source in the crust, relaxed toward
`temperature_option = 0`'s initial condition over the plate's age:

```cfg
[ic]
temperature_option = 1
continental_plate_age_in_yr = 100.e6   # age of the plate
radiogenic_heating_of_crust = 1.e-9    # W/kg
radiogenic_crustal_thickness = 30.e3   # m
lithospheric_thickness = 100.e3        # m
radiogenic_folding_depth = 10.e3       # m; e-folding depth of radiogenic heating (shared with option 2)
```

### `temperature_option = 2`: equilibrium temperature for crustal radiogenic heating

Like option 1, but for an arbitrary stack of radiogenic-heating layers
instead of a single crustal layer, each with its own material (and
therefore its own `therm_cond`, `rho0`, `radiogenic_heat_prod`):

```cfg
[ic]
temperature_option = 2
num_radiogenic_heat_layer = 1       # number of layers
radiogenic_heat_boundry = [-1,-1]   # depth of each layer boundary, top to bottom (m); -1 = model top/bottom
radiogenic_heat_mat_in_layer = [0]  # material index of each layer
radiogenic_folding_depth = 10.e3    # m; e-folding depth of radiogenic heating (shared with option 1)
```

### `temperature_option = 3`: continental thermal gradient with adiabatic mantle

A radiogenic continental geotherm, using the same layered `[mat]` properties
as option 2, capped by an adiabatic mantle below (via `mantle_temperature`
and gravity). The radiogenic heating of the top layer is driven by the heat
flux parameters below instead of `radiogenic_heat_prod`, and can be
localized under an elliptical "dome" in map view instead of applied
uniformly:

```cfg
[ic]
temperature_option = 3
num_radiogenic_heat_layer = 1       # number of layers (shared with option 2)
radiogenic_heat_boundry = [-1,-1]   # layer boundary depths, top to bottom (m); -1 = model top/bottom
radiogenic_heat_mat_in_layer = [0]  # material index of each layer
radiogenic_heat_dome_center_x = 0.5   # dome center, fraction of mesh.xlength
radiogenic_heat_dome_center_y = 0.5   # dome center, fraction of mesh.ylength (3D)
surface_heat_flux = 70e-3             # W/m^2, background surface heat flux away from the dome
radiogenic_heat_dome_amplitude = 0    # extra surface heat flux at the dome center
radiogenic_heat_dome_width = 0        # dome half-width (m); required (> 0) when this option is used
radiogenic_heat_dome_width_y = 0      # dome half-width in y (3D): 0 = same as x (circular), <0 = infinite (ridge/hinge)
radiogenic_heat_dome_azimuth = 0      # dome rotation (degrees, 3D)
```

### `temperature_option = 90`: read from an external grid

Reads a precomputed temperature field on its own mesh, interpolated onto
the DES3D mesh at startup, typically generated by COMSOL:

```cfg
[ic]
temperature_option = 90
Temp_filename = Thermal.dat         # rows of "x [y] z temperature"
Nodes_filename = Coord.dat          # rows of "x [y] z", may be ordered differently than Temp_filename
Connectivity_filename = Connectivity.dat   # rows of node indices per element (4 per row in 3D)
```

## Material thermal properties

The thermal diffusivity used above, and the diffusion solved every step, both
come from each material's properties in `[mat]` (one value per material, or
a single value broadcast to all materials):

```cfg
[mat]
heat_capacity = [1e3]        # J/(kg.K)
therm_cond = [3]             # W/(m.K)
radiogenic_heat_prod = [0]   # W/kg; internal heat source for temperature_option = 1-3
```

`mat.max_thermal_diffusivity` (default `5e-6` m²/s) caps the diffusivity used
for stability, in case a material's `therm_cond`/`rho0`/`heat_capacity`
combination would otherwise imply a larger one.
